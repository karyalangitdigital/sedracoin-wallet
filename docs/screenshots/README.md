# App Screenshots

Drop the app UI screenshots into **this folder** (`docs/screenshots/`). They are
displayed in the [top-level README](../../README.md) under **Screenshots**.

## Required file names

Use these exact names so the README image links resolve:

| File                | Screen shown            |
| ------------------- | ----------------------- |
| `home.png`          | Home & balance          |
| `send.png`          | Send SDR                |
| `receive.png`       | Receive / QR address    |
| `assistant.png`     | Sedra Assistant         |
| `utxos.png`         | UTXO management         |
| `settings.png`      | Settings                |

## Tips

- Formats: `.png` or `.jpg` (PNG preferred for crisp text).
- Recommended capture size: phone aspect ratio, around **720 × 1500 px**.
- Keep each image under ~500 KB so the repo stays lean.
- Prefer a device frame / consistent status bar for a polished look.

> If you use different file names, just update the `<img src="...">` links in the
> **Screenshots** section of the main README.
